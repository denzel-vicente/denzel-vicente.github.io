## 🚀 Running Locally

No bundlers or build steps required. You can serve the static files with any local HTTP server:

```bash
# Clone the repository
git clone https://github.com/denzel-vicente/denzel-vicente.github.io.git
cd denzel-vicente.github.io

# Option 1: Python 3 HTTP Server
python3 -m http.server 8000

# Option 2: Node npx serve
npx serve .

# Option 3: VS Code Live Server
# Click "Go Live" on the bottom status bar
```

Open `http://localhost:8000` in your browser.
